# 🔍 Simple Searchable API with Express.js

This is a lightweight **Express.js** API that allows you to search data using **path parameters** and **query strings**.

## 🚀 Features

- Built with **Express.js**
- Search using:
  - **Path parameters** (e.g., `/api/user/:name`)
  - **Query parameters** (e.g., `/api/user?name=John&age=25`)
- CORS enabled for cross-origin requests
- **Nodemon** for live reloading in development mode

## 🛠 Installation & Setup

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
npm install
npm start
# The server will start on http://localhost:8000/api

# For development mode with live reloading using Nodemon:
npm run dev
